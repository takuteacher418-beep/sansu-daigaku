# 算数大学 Version 7.2

Version 7.1のゲームUIを維持し、形成的評価に必要な2機能を追加しました。

## 1. 教師による採点確認・修正

教師画面の「結果確認」を「採点・回答確認」へ強化しました。

- 児童・単元・確認状態による絞り込み
- 問題名や回答文の検索
- 児童の回答全文
- 同じ問題への過去の回答履歴
- 自動判定の得点と納得度
- 教師による得点修正
- 教師コメント
- 正解・部分正解・再提出への変更
- 教師確認状態を児童の成長記録にも表示

教師が「正解」に変更した場合、未獲得なら問題のEXPを付与します。
「再提出」に変更した場合は、児童画面に教師の助言が表示されます。

## 2. 再挑戦システム

教授を十分に納得させられなかった場合、回答を残したまま再挑戦できます。

- 前回の回答を自動保存
- 問題へ戻ると回答を復元
- 挑戦回数を表示
- 不足していたキーワードを助言として表示
- 教師コメントがある場合は最優先で表示
- 再提出した回答は別の履歴として保存
- 教師画面で回答の変化を時系列に確認可能
- 合格すると下書きを削除
