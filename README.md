# 算数大学 Version 10.0 — 第一段階

## 今回の開発範囲

機能はVersion 9.0を維持し、画面デザインと視認性を全面的に刷新しました。

### UDデザイン
- 全画面をBIZ UDPゴシック優先のフォント構成へ統一
- Windows、Chromebook、iPad、Macで利用できる代替フォントを設定
- 文字間隔、太さ、入力欄のフォーカス表示を改善
- 淡い背景と濃い文字色でコントラストを確保

### 明るい画面デザイン
- 暗い紺色中心の画面から、白・青・緑を中心とした明るい配色へ変更
- カードの境界、影、余白を整理
- 操作ボタンを大きくし、アイコンと説明文を併記
- ミッション、成果、次の成長を色分け

### キャンパス成長マップ
- 絵文字だけの建物表示から、キャンパス全景イラストへ変更
- 本館、図書館、研究室、中庭、学生ホールを地図上へ配置
- 施設レベルを星で表示
- 未解放施設は薄く表示

## フォントについて

フォントファイルは同梱していません。
端末にBIZ UDPゴシックがある場合は優先して使用し、ない場合はUD教科書体、
游ゴシック、ヒラギノ角ゴシック、Noto Sans JPの順で表示します。
