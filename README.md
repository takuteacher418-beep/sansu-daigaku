# 算数大学 Version 11.3 スモールステップ搭載版

問題選択を中心にしたホーム画面と、拡大表示される教授システムを搭載した版です。

## 追加・変更
- ホーム中央を問題選択画面に再設計
- 教授はホームで大きく表示せず、担当教授の小さな表示だけに整理
- 「教授一覧を見る」を押すと教授7名を大きなカードで表示
- 教授画像を余白なくカードいっぱいに表示
- 教授カードを押すとプロフィール、得意分野、セリフ、担当問題を表示
- 問題画面の教授は問題を邪魔しない小さめ表示
- Version 11.2表記へ更新

index.html

## Version 11.3 追加機能
- 「自分で解く／少しずつ解く」の進め方選択
- 一文ずつ表示
- 読んでいる場所の強調
- 前の文・次の文による問題文ナビゲーション
- 式カードによる回答
- 文章・選択・式・文の型から回答方法を選択
- 問題ごとのスモールステップ
- 各段階で「できた部分」を示すフィードバック
- 読み上げ・ふりがな・図・ヒント等の利用記録
- 回答時間、回答形式、進め方の記録
- 教師画面で支援別の利用回数・平均点・平均時間を確認

## 注意
スモールステップは診断や能力判定を行うものではありません。
児童が問題へアクセスしやすくするための学習支援として実装しています。
