# 算数大学 Version 12.1 アクセシビリティ・デバッグ版

問題選択を中心にしたホーム画面と、拡大表示される教授システムを搭載した版です。

## 追加・変更
- ホーム中央を問題選択画面に再設計
- 教授はホームで大きく表示せず、担当教授の小さな表示だけに整理
- 「教授一覧を見る」を押すと教授7名を大きなカードで表示
- 教授画像を余白なくカードいっぱいに表示
- 教授カードを押すとプロフィール、得意分野、セリフ、担当問題を表示
- 問題画面の教授は問題を邪魔しない小さめ表示
- Version 11.2表記へ更新

## Version 11.3 追加機能
- 「自分で解く／少しずつ解く」の進め方選択
- 一文ずつ表示
- 読んでいる場所の強調
- 前の文・次の文による問題文ナビゲーション
- 式カードによる回答

- 問題ごとのスモールステップ

- 読み上げ・ふりがな・図・ヒント等の利用記録

## 注意
スモールステップは診断や能力判定を行うものではありません。
児童が問題へアクセスしやすくするための学習支援として実装しています。


## Version 11.5
- 説明問題の後に、実際の計算・文章問題を出題
- 同じ説明を繰り返し選ぶだけの確認問題を廃止
- 平均では、実際に平均を求める3問を出題
- 割合では、実際に割合を求める3問を出題
- 確認問題も選択式または穴埋め式のみ
- 正答後・誤答後に、その問題の解き方を表示
- 正しい説明は必要なときだけ開いて確認
- 教師は「平均」「割合」のテンプレートから確認問題を自動作成可能
- その他の単元では、テストに近い確認問題を手動で3問登録可能

説明を知っているかだけでなく、その知識を実際の問題に使えるかを別段階で確認します。


## Version 11.6
- 小学校1年生から6年生までの説明問題を搭載
- 各学年10問、合計60問
- すべての問題に、選択式・穴埋め式の説明問題を設定
- 各問題の後に、実際のテストに近い確認問題を3問設定
- 児童の登録学年の問題を初期表示
- 他学年または全学年へ切り替え可能
- 学年を選んだ後、その学年の単元で絞り込み可能
- 今日のおすすめも児童の登録学年から選択
- 教師が新しい問題を作る際に対象学年を設定可能
- 旧バージョンの保存データがあっても、新しいデフォルト問題を自動追加

### 搭載数
| 学年 | 問題数 |
|---|---:|
| 1年生 | 10 |
| 2年生 | 10 |
| 3年生 | 10 |
| 4年生 | 10 |
| 5年生 | 10 |

※ 学習指導要領上の全用語を完全収録したものではなく、各学年の主要な算数用語・考え方を広く収録した初期問題集です。


## Version 11.7
- 教師画面に「個別課題」タブを追加
- 児童を一人選んで問題を配信
- 配信時に短いメッセージを添付
- 児童ホームにメール風の小型ポップアップを表示
- 「あとで見る」でポップアップを閉じられる
- サイドバーの「先生からの課題」から再確認可能

### 現在の通信方式
Version 11.7は、同じブラウザのlocalStorageに保存された児童・教師データを共有する試作版です。
別の端末へリアルタイムに配信するには、今後Firebase、Supabaseなどのデータベースとの接続が必要です。

- 穴埋め本文を標準60問すべて再生成

## Version 12.1 提出箱・先生の丸つけ（第1段階）
- 全60問に「さいごの確認テスト」を1問ずつ追加
- 確認問題3問の後に確認テストを表示
- 児童は「丸つけをする」「先生に丸つけをしてもらう」から選択
- 自分で丸つける場合は、その場で正答と解説を表示
- 先生に頼む場合は、回答を提出箱へ保存
- 教師画面に「提出箱」タブと未確認件数バッジを追加
- 教師は児童の問題・回答・正答を確認
- ○・△・×を教師が選んで評価
- 300文字までのコメントを入力
- よく使うコメントのボタンを搭載
- 返却すると児童ホームへポップアップ通知
- 児童は丸・自分の答え・正しい答え・先生のコメントを確認可能
- 教師が作成したオリジナル問題にも確認テストを自動生成
- 音声録音と手書きCanvasは第2・第3段階の拡張用

### 現在のデータ共有
この版も同じブラウザのlocalStorageを使用します。教師端末と児童端末を分けて運用するには、FirebaseやSupabaseなどへの接続が必要です。
