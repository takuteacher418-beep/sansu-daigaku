# 算数大学 Version 11.4 説明練習特化版

問題選択を中心にしたホーム画面と、拡大表示される教授システムを搭載した版です。

## 追加・変更
- ホーム中央を問題選択画面に再設計
- 教授はホームで大きく表示せず、担当教授の小さな表示だけに整理
- 「教授一覧を見る」を押すと教授7名を大きなカードで表示
- 教授画像を余白なくカードいっぱいに表示
- 教授カードを押すとプロフィール、得意分野、セリフ、担当問題を表示
- 問題画面の教授は問題を邪魔しない小さめ表示
- Version 11.2表記へ更新

## Version 11.3 追加機能
- 「自分で解く／少しずつ解く」の進め方選択
- 一文ずつ表示
- 読んでいる場所の強調
- 前の文・次の文による問題文ナビゲーション
- 式カードによる回答
- 文章・選択・式・文の型から回答方法を選択
- 問題ごとのスモールステップ
- 各段階で「できた部分」を示すフィードバック
- 読み上げ・ふりがな・図・ヒント等の利用記録
- 回答時間、回答形式、進め方の記録
- 教師画面で支援別の利用回数・平均点・平均時間を確認

## 注意
スモールステップは診断や能力判定を行うものではありません。
児童が問題へアクセスしやすくするための学習支援として実装しています。


## Version 11.4 追加・変更
- 自由記述・長文入力を廃止
- 回答形式を「選択式」「穴埋め式」に限定
- 正しい説明を確認した後、確認問題を自動で3問出題
- 確認問題は選択式・穴埋め式のみ
- 平均・割合では概念を使う練習問題を自動生成
- 教師は正しい説明、誤った説明、穴埋め語を入力するだけで作成可能
- 作成時に選択問題、穴埋め問題、確認問題3問を自動構成
- 児童の説明確認結果と練習問題の正答数を保存

## 設計意図
計算ドリルではなく、算数の用語や考え方を説明する力の練習に特化しています。
文字を書くこと自体が障壁にならないよう、回答はすべて選択または穴埋めで行います。
