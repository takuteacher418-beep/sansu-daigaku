# 算数大学 Version 4.2

## 教師用問題作成画面の改善

問題作成を次の4段階に整理しました。

1. 単元を選ぶ
2. 児童に出す問題を書く
3. 評価する考えを確認する
4. 問題を保存する

## 主な変更
- 入力順が分かる番号付き画面
- 必須項目と任意項目を表示
- 単元テンプレートを最初に配置
- 入力中の児童画面プレビュー
- 評価観点と同義語の説明を追加
- 学年、難易度、模範解答、満点などを「詳細設定」に収納
- 一番大切な保存ボタンを大きく表示
- 「新しい問題を作る」ボタンを追加
- Version 4.1の問題復元機能と研究レベル評価を維持
