# 算数大学 Version 10.1 — 画像埋め込み版

## 改善内容

キャンパス成長マップの画像を、外部の画像ファイルではなく
`index.html`の中へBase64形式で直接埋め込みました。

そのため、GitHubへ`assets`フォルダや画像ファイルをアップロードする必要はありません。

## GitHub Pagesへアップロードするファイル

次の4ファイルをリポジトリの一番上へ置いてください。

- index.html
- style.css
- app.js
- .nojekyll

画像は`index.html`に含まれています。

## 注意

以前アップロードした`campus-map-v10.jpg`や`assets`フォルダが残っていても、
Version 10.1では使用しません。削除しても問題ありません。

## データ

Version 10.0までの児童データ、問題データ、教師設定をそのまま使用します。
