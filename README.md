# 算数大学 Version 3.0

## 新機能

### 算数大学キャンパス
- 学習記録から研究ポイント（RP）を計算
- 本館・中庭・図書館・研究棟・講堂・天文台を順番に解放
- 次の建物までの進行状況を表示
- 今日の研究ミッション
  - 問題に1回挑戦
  - 問題を1問クリア
  - AI教授に1回相談

### 無料版AI教授
- API・外部サービス・通信不要
- 児童の入力語句と選択単元をもとに返答
- 答えを直接示さず、考える順番や算数用語を案内
- 単元ごとのヒント
- クイック質問ボタン
- 児童ごとに直近の会話を端末内保存

データは使用中の端末・ブラウザ内に保存されます。
