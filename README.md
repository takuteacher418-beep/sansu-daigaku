# 算数大学 Version 9.0

## キャンパスホーム全面リニューアル
- 大きすぎたタイトル表示を廃止
- 学生情報を左側へコンパクトに集約
- キャンパス成長マップを中央に表示
- 今日のミッション、最近の成果、次の成長を追加

## 成長の反映
教授を納得させると、総EXP・研究ポイント・キャンパスEXP・クリア数を児童データへ保存します。
キャンパスへ戻るたびに最新値を再表示します。

## レベルアップ演出
学生レベルまたはキャンパス施設が成長した場合、全画面のLEVEL UP演出を表示します。

## 旧データとの互換性
Version 8.1以前の児童データにも、不足項目を自動追加します。

## GitHubへの反映
ZIP内の `index.html` と `.nojekyll` を上書きしてください。
