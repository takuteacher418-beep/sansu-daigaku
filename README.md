# 算数大学 Version 10.5 — 第二段階「世界観デザイン」

Version 10.1の学習機能と保存データを維持しながら、次の4項目を導入しました。

## 1. 教授キャラクターの統一リデザイン
- 7人の教授を同一の頭身・線・塗りで描いたオリジナルSVGへ変更
- 通常・思考中・納得の3表情を用意
- 各教授の専門を、色・記号・持ち物で表現
- 教授選択画面、バトル画面、勝利画面へ反映

## 2. 建物の高品質ベクターイラスト化
- 本館
- 図書館
- 研究室
- 中庭
- 学生ホール
を個別のオリジナルSVGとして描画しました。

## 3. アイコン・ボタン・ブランドの統一
- ホームメニューの絵文字をベクターアイコンへ変更
- ミッション、成果、成長の見出しをゲーム風エンブレムへ変更
- 推奨教授、EXP、教授名札などの意匠を統一

## 4. キャンパスレベルによる見た目の変化
- Lv.1：大学の始まり
- Lv.3：噴水が稼働
- Lv.5：花が咲く
- Lv.7：時計台が完成
- Lv.10：大学祭モード

未解放の建物は暗く表示され、条件達成後にカラー表示へ変化します。

## GitHub Pagesへの反映
次の4ファイルをリポジトリの一番上で上書きしてください。

- index.html
- style.css
- app.js
- .nojekyll

教授・建物のSVG画像はapp.js内へ埋め込まれているため、画像フォルダは不要です。
