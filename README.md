# 算数大学 Version 7.0.2

## 修正1：勝利画面の常時表示を解消

「完全納得！」の勝利画面は、教授を納得させたときだけ表示されます。
通常のキャンパス・単元選択・問題選択画面では表示されません。

## 修正2：回答の途中保存

教授バトル中の回答を保存できるようにしました。

- 入力後、0.5秒で自動保存
- 「途中保存」ボタンで手動保存
- 問題選択画面へ戻っても回答が残る
- ログアウトやページ再読み込み後も、同じ児童・同じ問題なら回答を復元
- 問題をクリアすると保存した下書きを自動削除
- 児童ごと、問題ごとに別々に保存
