# 算数大学 Version 4.3

## 問題作成をさらに簡単にしました

通常は次の3操作だけです。

1. 単元を選ぶ
2. 問題タイトルと問題文を書く
3. 「この問題を保存する」を押す

ヒント、模範解答、評価観点、同義語は単元テンプレートから自動設定されます。
細かく変更したい場合だけ「細かく設定する」を開きます。

## 重複問題の修正

- 保存ボタンの連続クリックを防止
- 同じ単元・タイトル・問題文の重複登録を防止
- 「児童画面で確認」は問題を保存しない仕様に変更
- 既に保存されている完全重複問題は起動時に1件へ整理

## GitHubへの反映

ZIPを展開し、GitHubの `index.html` を上書きしてください。
