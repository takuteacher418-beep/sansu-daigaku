# 算数大学 Version 11.1 教授システム搭載版

児童ボタン・教師ボタン・各画面遷移が動作するように、複数ファイル構成で作り直した版です。

## デモログイン
- 児童：aoi01 / 1234
- 教師：4180

## 動作する機能
- 児童／教師タブ切り替え
- 児童ログイン、教師ログイン、ログアウト
- 問題一覧、単元フィルター、問題挑戦
- 読み上げ、ふりがな、文字拡大、ヒント
- 文章回答、選択回答、文の型
- 簡易採点、経験値、ポイント、履歴
- 学習プロフィール表示
- 教師ダッシュボード
- 児童登録・編集
- 支援設定の反映
- 問題登録・編集
- 学習結果一覧

## 公開方法
ZIPを展開し、フォルダ構成を崩さずにGitHubリポジトリ直下へアップロードしてください。

## LDIRについて
現在は仮の支援設定項目です。正式なLDIR項目・採点方法を入力いただければ、項目入力画面、自動集計、プロフィールへの反映ロジックを追加できます。


## Version 11.1 追加機能
- オリジナル教授7名の画像
- 教授一覧画面
- 教授ごとの得意分野・性格・あいさつ
- 問題ごとの担当教授表示
- ホームのおすすめ問題に担当教授を反映
- 採点結果に教授ごとの成功・再挑戦メッセージを表示
- 画像は `images/professors/` に分離して管理
