# 算数大学 Version 1.0

小学5年生を対象に、算数用語や考え方を文章で説明する学習用Webアプリです。

## 主な機能

- 児童用の問題一覧画面
- 問題を選んで文章で回答
- キャラクターによる案内
- 教師用の問題作成画面
- 採点基準と配点の設定
- 問題一覧への追加
- 簡易自動採点
- できている点と改善点の表示
- ブラウザ内への設定保存

## GitHubへのアップロード方法

1. このZIPファイルを展開します。
2. GitHubの `sansu-daigaku` リポジトリを開きます。
3. `Add file` → `Upload files` を選びます。
4. 次の3ファイルをアップロードします。
   - `index.html`
   - `README.md`
   - `.nojekyll`
5. 画面下部の `Commit changes` を押します。
6. 数分待ってから、次のURLを開きます。

`https://takuteacher418-beep.github.io/sansu-daigaku/`

## 注意

現在の採点は、教師が設定した語句や文章の長さを使った簡易判定です。
生成AIによる意味理解型の採点、児童ログイン、回答保存、クラス管理などは今後追加する予定です。
