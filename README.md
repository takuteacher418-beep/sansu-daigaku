# 算数大学 Version 5.1

## 修正内容

- 「この単元を保存する」ボタンの処理を修正
- 単元名入力欄で Enter を押しても保存可能
- 単元説明欄では Ctrl+Enter / Command+Enter で保存可能
- 単元削除の確認画面を追加
- 「単元だけ削除」では問題を未所属へ移動
- 「単元と問題をすべて削除」では関連問題も削除
- 単元編集後の保存処理を安定化
