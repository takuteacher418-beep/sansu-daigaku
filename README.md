# 算数大学 Version 8.0

## 問題作成アシスタント

教師画面の問題作成に、4段階のウィザードを追加しました。

1. 学年・単元・問題タイプを選ぶ
2. 育てたい力・難易度・作成数を選ぶ
3. 問題候補を自動生成する
4. 内容を確認して問題作成画面へ反映する

## 自動で提案する内容

- 問題タイトル
- 問題文
- 模範解答
- 重要キーワード
- 類語・言い換えグループ
- ヒント
- 推奨教授
- 難易度
- 合格に必要なキーワード一致率
- 満点

## 現在の方式

Version 8.0はGitHub Pagesだけで動くように、外部AI APIを使わないテンプレート・辞書方式です。

平均・割合・速さ・体積には専用テンプレートがあります。
その他の単元には汎用の説明問題テンプレートを使います。

生成後は通常の問題作成画面へ反映されるため、教師が自由に修正してから保存できます。
