# 算数大学 Version 9.0 再構築版

## ファイル構成

- `index.html`：画面構造
- `style.css`：デザイン
- `app.js`：画面遷移、問題管理、バトル、保存処理
- `.nojekyll`：GitHub Pages用

## 修正した不具合

ホーム画面の「問題に挑戦する」「成長の記録」「大学の施設」は、
既存の画面遷移方式である `data-student-nav` と共通クリック処理を使用します。
個別のボタン処理を増やさず、画面遷移を一か所へ統一しました。

## 成長システム

教授を初めて納得させた問題について、次を児童データへ保存します。

- 総EXP
- 研究ポイント
- キャンパスEXP
- クリア済み問題
- 最近の成果

同じ問題をもう一度クリアした場合は、EXPの重複獲得を防止します。

## ホーム画面

- 算数大学の見出しをコンパクト化
- レベルとEXPゲージを常時表示
- キャンパス成長マップ
- 今日のミッション
- 最近の成果
- 次のキャンパスレベルまでの必要EXP
- レベルアップ・キャンパス成長演出

## GitHub Pagesへの反映

リポジトリ内の古いファイルを、このZIP内のファイルで置き換えてください。
`style.css` と `app.js` も必ずアップロードしてください。
