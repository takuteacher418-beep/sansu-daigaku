# 算数大学 Version 4.0

## 新機能

### 単元テンプレート
教師画面で単元を選ぶと、以下を自動入力します。
- 問題タイトル
- 問題文
- 模範解答
- ヒント
- 評価観点
- 同義語・子どもの表現

対応単元：
平均、割合、速さ、体積、単位量あたりの大きさ、面積

### やさしい評価
完全一致だけでなく、意味の近い言葉や子どもらしい言い換えも評価します。

例：
- 合計
- 全部足す
- 合わせる
- 全部集める

これらを近い考えとして扱います。

### 研究レベル
点数に加えてLv.1〜Lv.5を表示します。
- Lv.1 研究スタート
- Lv.2 考えを書けた
- Lv.3 大切な考えが伝わる
- Lv.4 友達にも伝わる説明
- Lv.5 先生レベルの説明

### ポイント獲得条件
従来よりクリア条件を緩和し、約70％の観点が伝わればクリア扱いになります。
