# 算数大学 Version 6.0

GitHub Pagesでそのまま公開できる、1ファイル構成のWebアプリです。

## 主な機能
- 豪華な紺・金デザインの新ロゴ
- 教師ログイン（初期パスコード：4180）
- 単元の作成・編集・削除
- 単元だけ削除／単元と問題をまとめて削除
- 作成済み単元から問題を作成
- 問題の編集・削除
- 児童登録・編集・削除
- 児童ログインと回答提出
- 回答履歴の確認
- データのJSON書き出し・読み込み
- localStorageによる端末内保存

## GitHubへの反映
1. ZIPを展開します。
2. GitHubの `sansu-daigaku` リポジトリを開きます。
3. `index.html` と `.nojekyll` をアップロードします。
4. 既存の `index.html` は上書きします。
5. GitHub Pagesを開き、`Ctrl + Shift + R` で強制再読み込みします。

## 注意
データは利用しているブラウザの端末内に保存されます。
別の端末へ移す場合は、設定タブからJSONを書き出してください。
