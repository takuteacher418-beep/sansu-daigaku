# 算数大学 Version 6.2

## 1. 児童回答画面の刷新

児童が回答を書く画面を「研究ミッション」のデザインに変更しました。

- 問題難易度と獲得EXPを目立つ位置に表示
- 問題を巻物風カードで表示
- ヒントを「たっくん教授のヒント」として表示
- 回答欄を白い研究ノート風に変更
- 入力文字数と入力メーターを表示
- 提出ボタンを大きく立体的なデザインに変更
- 得点後に、含まれていた大切な考えを表示

## 2. 幅を持たせた柔軟な正誤判定

完全一致ではなく、以下を組み合わせて評価します。

- 教師が設定した必須キーワード
- 教師が設定した言い換え・類語グループ
- 組み込みの基本的な算数類語
- 模範解答との部分一致
- 回答の説明量
- 教師が設定した合格一致率

### 教師画面での設定例

必須キーワード：

```text
全部の量
個数
等しくする
```

言い換え・類語グループ：

```text
全部｜合計｜総量
等しくする｜ならす｜均等にする
```

この場合、「全部の量を個数で割ってならした数」のような回答も、
模範解答と完全に同じ文章でなくても正解候補になります。

## 注意

この判定はブラウザ内で動くルールベース方式です。
文章の意味を人間と同じように完全理解するAI採点ではありません。
重要な問題では、教師用の結果確認画面で回答本文も確認してください。
