# 算数大学 Version 8.1

## 回答サポートモード

児童は問題に応じて、次の答え方を選べます。

- 自由記述
- 穴埋め
- 選択肢から文章を組み立てる
- 教授との会話形式

教師は問題ごとに回答方法を固定することも、児童に選択させることもできます。

## 段階ヒント

ヒントは一度に答えを示さず、ボタンを押すたびに1段階ずつ表示します。

## 教師用設定

問題作成画面に以下を追加しました。

- 回答形式
- 回答支援の強さ
- 段階ヒント
- 文章組み立て用の選択肢

問題作成アシスタントから生成した問題にも回答支援設定が入ります。
