# 算数大学 Version 7.0

## Version 7.0の中心設計

児童画面を、1枚の長いページではなく、ゲームのように画面全体が切り替わるSPA構成へ変更しました。

### 画面遷移

1. キャンパス（ホーム）
2. 単元選択
3. 問題一覧
4. 教授選択
5. 教授バトル
6. 完全納得・勝利
7. 成長の記録
8. 大学の施設

## 教授バトル

- 画面上部に教授の大きな立ち絵を表示
- 教授の吹き出しの中に問題を表示
- 画面下部に回答入力欄を固定
- 回答によって納得度ゲージが上昇
- 不十分な場合は教授が追加説明を求める
- 合格時は勝利画面へ完全に遷移
- 初回クリアEXPと研究ポイントを表示

## 教授

- 論理のアルベルト教授
- 平均のメディアン教授
- 割合のレシオ教授
- 図形のジオメト教授
- 速さのヴェロ教授
- 数のニュメロ教授
- 謎のゼロ教授

教授画像は `assets/professors` に入っています。

## 教師画面

Version 6.3までの機能を維持しています。

- 教師ログアウト
- 単元管理
- 問題作成
- 児童管理
- 結果確認
- 模範解答・キーワード・類語による柔軟な判定
- 問題ごとの推奨教授設定
