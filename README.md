# 算数大学 Version 3.3

## 修正内容

### 問題が表示されない問題
新しい画面から削除された旧レベル表示部品を、JavaScriptが参照していたため、
問題一覧を描画する前にエラーで停止していました。

- 存在しない表示部品を参照しても停止しないよう修正
- 問題一覧の描画を初期化処理の先頭に変更
- 問題カードと問題数表示を安全に描画
- 問題が0件の場合は案内を表示

### 算数大学ロゴ
- 参考画像から中央の校章部分だけを切り直し
- 左右の人物・ポイント表示・周囲のパネルが入らないよう修正
- HTML内に画像を埋め込んでいるため、別画像のアップロードは不要

## GitHubへの反映
