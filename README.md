## 児童ログイン
児童は、先生が登録した個別のログインIDとパスワードでログインします。

初期登録例：
- あおい：ID `aoi01` / パスワード `1234`
- けんた：ID `kenta01` / パスワード `1234`
- さくら：ID `sakura01` / パスワード `1234`

教師画面から、児童のIDとパスワードを追加・編集できます。

## 更新方法
GitHubの `index.html` を上書きしてください。
その後、公開ページで `Ctrl + Shift + R` を押して強制再読み込みしてください。

## 注意
データは使用中の端末・ブラウザ内に保存されます。
複数端末で共有する本格ログインには、今後クラウドデータベースが必要です。
