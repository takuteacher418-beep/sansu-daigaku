# 算数大学 Version 6.1

Version 6.0の豪華な紺・金デザインに、以前の成長・経験値システムを追加しました。

## 追加した機能

- 児童ごとの総経験値（EXP）
- 100EXPごとのレベルアップ
- レベルに応じた称号
- 初回クリア時の経験値獲得
  - 基礎：25EXP
  - 標準：50EXP
  - 発展：75EXP
- 研究レベル Lv.1〜5
- 問題ごとの挑戦回数と最高点
- クリア済み問題数
- 研究ポイント（EXP＋挑戦回数×5）
- 研究ポイントに応じたキャンパス成長
  - 本館
  - 中庭
  - 図書館
  - 研究棟
  - 講堂
  - 天文台
- レベルアップ演出
- 教師の結果確認画面に研究レベルと獲得EXPを表示

## 経験値のルール

得点率70％以上で問題クリアです。
同じ問題から経験値を得られるのは、児童ごとに初回クリア時のみです。

## データ保存

経験値やキャンパスの成長は、児童ごとのデータとしてブラウザ内に保存されます。
Version 6.0の児童データを読み込んだ場合も、進捗データは自動的に補われます。

## GitHubへの反映

ZIPを展開し、`index.html`と`.nojekyll`をGitHubへアップロードしてください。
既存の`index.html`は上書きします。
