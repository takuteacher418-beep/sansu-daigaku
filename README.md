# 算数大学 Version 7.1

## 7人の教授を個別デザイン化

教授ごとに異なる立ち絵を組み込みました。

- 論理のアルベルト教授
- 平均のメディアン教授
- 割合のレシオ教授
- 図形のジオメト教授
- 速さのヴェロ教授
- 数のニュメロ教授
- 謎のゼロ教授

画像はindex.html内部へ埋め込まれているため、画像フォルダは不要です。

## リアクション状態

各教授に3つの表示状態があります。

- 通常
- 思考中
- 納得

採点ボタンを押すと教授が思考中になり、採点後に通常または納得状態へ変化します。

## 教授ごとの口調

教授の専門分野と性格に合わせて、以下のセリフを個別設定しています。

- 問題出題時
- 採点中
- もう一歩の回答
- 完全に納得した回答

## 得意分野エフェクト

- 論理：青い思考記号
- 平均：天秤・総和・平均記号
- 割合：百分率・比・円グラフ
- 図形：三角形・角・円周率
- 速さ：時計・速度記号
- 数：数字・無限記号
- ゼロ：零・疑問符・金色粒子

回答を提出したときと完全納得時に、教授の周囲へ専用エフェクトが表示されます。

## BGM

Version 7.1にはBGMファイルは含めていません。
後から教授ごとのBGMと効果音を追加できる設計に拡張できます。
